# WebMCP tools

This site offers optional, read-only tools for browser agents: read the mining status, check OS and GPU requirements, and retrieve the setup prompt or playbook. They read the same public manifest as this website.

The tools cannot install software, access wallets, make payments or grant a local shell. You authorize any work on your computer separately.

Browser support varies. If your browser does not support WebMCP, the guides, selectable prompts and [machine-readable manifest](/mine.json) still work.
